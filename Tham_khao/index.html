🔑 Cài đặt AI Gemini Key (Dành cho RAG Engine)
Để kích hoạt khả năng suy luận tự do với Google Gemini, hãy nhập API Key của bạn. Key sẽ chỉ lưu trong bộ nhớ trình duyệt (localStorage) trên máy của bạn.
💾 Trung tâm Lưu trữ & Đồng bộ Dữ liệu
Chưa bật tự động lưu — thay đổi được lưu tạm trong trình duyệt (localStorage).
📂
Tự động lưu vào thư mục trên máy (khuyên dùng) Chọn thư mục bất kỳ (VD: thư mục Google Drive/OneDrive đồng bộ). Mọi thay đổi tự ghi ngay vào file lexbuild-data.json, mở lại app tự nạp. Yêu cầu Chrome/Edge.
🔄
Kết nối Google Sheet — đồng bộ realtime cho cả team Dán link Google Sheet (chia sẻ "Bất kỳ ai có link"). App tự đồng bộ mỗi 60 giây — cả team cập nhật 1 nguồn, mọi máy đều thấy.
Link Google Sheet (cột theo thứ tự: Lĩnh vực/Nhóm | Loại | Số hiệu | Tên/Nội dung | Ngày BH | Ngày HL | Ngày hết HL | Link DOCX | Link PDF | Cơ quan | Tóm tắt/Ghi chú)
📡
Theo dõi 1 file dữ liệu — tự động cập nhật liên tục Chọn 1 file Excel/JSON làm nguồn dữ liệu chính. App kiểm tra mỗi 30 giây, file đổi là nạp lại ngay. Đặt file trong thư mục Google Drive để cả team cùng cập nhật. Yêu cầu Chrome/Edge.
📋
Tải mẫu Excel chuẩn (1 sheet DATABASE đầy đủ dữ liệu) Xuất toàn bộ văn bản về 1 sheet chuẩn 12 cột — chỉnh sửa trên Excel rồi nạp ngược lại app. Tương thích cấu trúc file APCC/XDV Thư viện Luật XD.
🔁
Cập nhật / thay toàn bộ dữ liệu từ file Excel mẫu Chọn file mẫu đã chỉnh sửa — app thay toàn bộ dữ liệu theo file (nhận cả mẫu LexBuild lẫn mẫu XDV/APCC 11 cột). Có xác nhận trước khi thay.
⬇️
Tải file dữ liệu (JSON) về máy — backup Lưu snapshot toàn bộ dữ liệu để backup hoặc chuyển sang máy khác.
📥
Nạp lại file dữ liệu (JSON) đã lưu Khôi phục dữ liệu từ file JSON đã tải trước đó (nhận cả JSON của app XDV Thư viện Luật).
📊
Xuất toàn bộ ra Excel (.xlsx) nhiều sheet theo lĩnh vực Xuất kho văn bản thành file Excel mỗi lĩnh vực 1 sheet — đồng bộ ngược về file Excel APCC gốc.
